# AGENTS.md — Nothing

Instant NTFS file search for Windows (Everything-class): Rust workspace, raw Win32 via `windows-sys`, a SYSTEM indexing service plus a native GUI, talking over a named pipe.

## Commands
- Run UI: `cargo run --release -p nothing` (add `-- --folder <dir>` to open scoped to a folder)
- Run service in a console (elevated prompt): `cargo run --release -p nothing-svc -- --console` (`--for <secs>` auto-stops)
- Benchmark without admin: `cargo run --release -p nothing-svc -- --walk C:\ --bench <query>`; raw MFT: `--scan C: --bench <query>` (elevated)
- Test (all): `cargo test`
- Test (single): `cargo test -p nothing-core <test_name>`
- Build (default members): `cargo build --release`
- Build legacy installer: `build-installer.cmd` -> `target\release\nothing-setup.exe`

## Architecture
- `crates/core` (`nothing-core`) — index SoA model, query parser/matcher (`search.rs`), case folding, persistence, pipe protocol (`proto.rs`, pipe `\.\pipe\nothing-index`). No Win32 UI code here.
- `crates/svc` (`nothing-svc.exe`) — MFT reader (`mft.rs`), USN tailer (`usn.rs`), Windows service (`service.rs`), pipe server (`server.rs`); index persisted under `%ProgramData%\Nothing`.
- `crates/ui` (`Nothing.exe`) — Win32 window + virtual listview (`app.rs`), pipe client (`ipc.rs`), `--install`/`--uninstall` elevation (`install.rs`), settings in `%APPDATA%\Nothing\settings.ini`; exe manifest/icon generated by `res.rs`.
- `crates/shellext` (`nothing_shell.dll`) — Explorer context-menu cdylib; launches `Nothing.exe --folder <path>`.
- `crates/setup` (`nothing-setup.exe`) — legacy elevated installer embedding the release exes; builds `nothing.msix` from `package/AppxManifest.xml` in `build.rs`. Excluded from `default-members`.
- **Version Manifests:** `Cargo.toml` (`[workspace.package] version`), `gloria.toml` (`version`) — keep in lockstep; all crates inherit `version.workspace = true`.

## Personal Rules (Brain)
- **Commit Format:** Write one plain sentence stating what changed and why; do not use `feat:`/`fix:`/`chore:` conventional-commit prefixes.
- **Path Privacy:** Always use `C:\Users\you` in documentation, comments, and examples—never hardcode the local machine's real username.
- **Git Branching:** Never create new branches or git worktrees. Always work directly on `main` until explicitly told otherwise.
- **Versioning (Major/Minor Changes):** Before changing minor/major versions or dropping `-alpha` on breaking or major feature work, stop and ask for the exact target version.
- **Window Chrome:** Disable native OS titlebars; build an integrated frameless titlebar with drag region, double-click maximize, and custom min/max/close controls.
- **Desktop Shell Lock:** Lock the app shell to `100vw x 100vh` (`overflow: hidden`) with internal scroll panes and `user-select: none` on UI chrome.
- **Scrollbars:** Ban raw OS scrollbars; use thin (4–6px) themed scrollbars with transparent tracks and zero layout shift.
- **Interactive Controls:** Custom-style all form controls; define explicit `hover`, `active`, `focus-visible`, and `disabled` states with snappy 120–180ms transitions.

## Repo Guardrails & Gotchas
- **Commit & Push Policy:** Never run `git commit`, `git tag`, or `git push` unless explicitly asked; never force-push to `main`. On "commit and push": verify build and tests, confirm version manifests are synced, commit on `main`, push to `origin main`. Releases here are tag-driven: `.github/workflows/release.yml` runs only on `v*` tags (or manual dispatch), so a push to `main` publishes nothing.
- **Versioning (Minimal Changes):** Versions are plain `X.Y.Z` (no `-alpha`): `crates/setup/build.rs` and `crates/ui/res.rs` turn `CARGO_PKG_VERSION` into a 4-part numeric MSIX/PE version, which a prerelease suffix breaks. Bump the patch at most once per uncommitted change set (check `git diff HEAD`); skip bumps on docs-only tasks.
- **Release Packaging:** CI packs only `Nothing.exe`, `nothing-svc.exe`, `nothing_shell.dll` with `projectGloria/GloriaSetup@v0.1.0` (per-user); it does not register the `Nothing Index` service, the logon entry, or `nothing.msix`. See `GLORIA_ROLLOUT.md` for open decisions.
- **Static CRT:** `.cargo/config.toml` sets `+crt-static` for `x86_64-pc-windows-msvc`; keep it so exes run without the VC++ redistributable.
- **Privileges:** MFT/USN access needs `SeBackupPrivilege` (service or elevated console); use `--walk` for unelevated testing.
- **Dependencies:** Runtime deps are only `windows-sys` and `memchr`; no async runtime or GUI framework.

## Done Criteria
- `cargo build --release` and `cargo test` pass; if `crates/setup` or packaging changed, `build-installer.cmd` succeeds.
- For runtime/packaging changes, `Cargo.toml` and `gloria.toml` versions match.
